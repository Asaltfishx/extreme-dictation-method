# 03 — 核心解法：白紙審判與 100 篇微型短文

竹岡廣信的解法可以濃縮為一句話：**放棄長篇大論，精選 100 篇微型短文，並透過名為「白紙審判」的嚴苛機制進行訓練。**

## 一、微型短文的優勢

每篇短文僅 **50 到 80 個單字**（約 3 到 5 個完整句子），背誦只需要約 **15 分鐘** [08:31]。

### 為什麼是這個長度？

- **心理門檻低**：15 分鐘是一個「隨時可以開始」的單位，再忙的一天也擠得出來。
- **正向反饋強**：每完成一篇，就是一次完整的「我也能做到」。這種即時的成就感，是支撐成人持續學下去的**唯一動力**。
- **對比長篇背誦**：幾百字的文章背到後面忘前面，永遠到不了「完成」的節點，意志力在半路上就耗盡了。

### 萬能的底層代碼

這 100 篇短文不是隨便找的，而是：

- 濃縮了各種**核心句型**：條件句、倒裝句、虛擬語氣、定語從句、非謂語動詞等。
- 包含嚴謹的**邏輯結構**與高頻**詞組搭配**。
- 等同於將英文的底層運作系統直接植入大腦——內化之後，面對任何新場景都能自動組裝出正確的英文。

## 二、白紙審判（Blank Paper Trial）

「白紙審判」是整個方法的心臟，由兩個缺一不可的部分組成：

### 白紙：徹底切斷視覺依賴 [07:08]

- 不看課本、不看任何中文翻譯。
- 面前只留一張白紙和一枝筆。
- 逼迫大腦在**毫無提示的絕境**下進行深度的「主動提取」。
- 嚴禁在腦中先想中文：救你的應該是腦中的英文音韻節奏，而不是中文翻譯。

### 審判：對錯誤「零容忍」

- 在白紙上，**漏掉一個冠詞、單複數寫反、拼錯一個字母，全視為錯誤**。
- 毫不留情地戳破「我以為我背好了」的錯覺。
- 熟悉感 ≠ 掌握：能看懂、能跟讀，不代表能在白紙上一個字不差地還原。

## 三、為什麼這套組合有效？

```
微型短文（低門檻 + 高頻反饋）  →  讓你願意開始、能夠堅持
白紙（切斷依賴 + 主動提取）    →  讓大腦真正流汗、形成髓鞘加固
審判（零容忍 + 戳破錯覺）      →  確保內化的是正確的版本，而非錯誤的肌肉記憶
```

三者缺一不可：沒有微型短文，你堅持不下去；沒有白紙，你只是在自我感動；沒有審判，你會把錯誤也練成習慣。
