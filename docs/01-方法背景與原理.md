# 01 — 方法背景與原理

## 竹岡廣信：傳奇英語補教名師

- 日本傳奇英語補教名師，以極其嚴苛、高效的教學風格聞名。
- 知名日劇及漫畫《龍櫻 / 東大特訓班》中英語教師的**原型人物**。
- 其教學方法的核心主張：**徹底治好學生的「啞巴英語」**，讓大腦建立真正的母語者直覺 [00:15]。

## 《Dragon English 基本英文100句》

- 竹岡廣信的代表作，被日本考生奉為**神級參考書**。
- 書中收錄了他所推崇的「暗記暗誦法」（本專案稱之為「極限默寫法」）。
- 方法主打：透過殘酷但極高效的訓練，把英文從「知識」變成「本能」。

## 方法的核心主張

### 1. 啞巴英語的病根：只有輸入，沒有提取

多數學習者把大量時間花在「看」和「聽」上（輸入），卻極少逼迫自己在毫無提示的情況下把英文「生產」出來（提取）。
結果是：看得懂、聽得懂，一開口一動筆就大腦空白——典型的啞巴英語。

### 2. 解藥：主動提取（Active Recall）

- 學習科學早已證實：**主動提取**比反覆閱讀更能鞏固長期記憶。
- 極限默寫法把主動提取推到極致：在一張白紙面前，不看課本、不看中文翻譯，逼大腦在「絕境」下把每一個單字、每一個標點都生產出來 [07:08]。
- 當你經歷劇烈的「認知摩擦」（瘋狂搜刮確切單字或時態）時，神經元正在分泌髓鞘、加固這條神經迴路。**這種痛苦，就是語言內化為本能的「生長痛」** [13:50]。

### 3. 快樂學習的遮羞布

這套方法直接挑戰了「快樂學習」的迷思：

> 沒有痛苦的深度提取，就沒有真正的肌肉記憶。

- 輕鬆的學習方式（看看劇、背背單字 App）帶來的是「熟悉感的錯覺」，而非真正的所有權。
- 只有當大腦為每一個語言單位「流過汗」，它才會把這些單位登記為自己的東西。

### 4. 萬能的底層代碼

這 100 篇微型短文不是隨便找的：

- 濃縮了各種**核心句型**（條件句、倒裝句、虛擬語氣等）及嚴謹的邏輯結構。
- 等同於將英文的**底層運作系統**直接植入大腦。
- 一旦內化，面對任何新場景，大腦都能調用這套底層代碼自動組裝出正確、地道的英文，而不是逐字翻譯中文。
