# 素材挑選檢查表

> 每篇候選短文在進入默寫流程前，必須逐項通過以下檢查。任一項不通過 → 修改或捨棄。

## 基本信息

- 短文編號：
- 標題 / 主題：
- 目標場景：（技術闡述 / 商務交涉 / 問題排查 / 考試寫作 / 其他）
- 來源：（白皮書 / 商業函件 / Economist / BBC 6 Minute English / 自行蒸餾）
- 來源連結：

## 檢查項

### 準則一：長度與密度

- [ ] 字數在 50–80 字之間（實際字數：___）
- [ ] 3–5 個結構完整的句子（實際句數：___）
- [ ] 包含至少 1 個核心語法現象（虛擬語氣 / 倒裝 / 定語從句 / 非謂語動詞 / 其他：___）
- [ ] 包含 2–3 個母語者高頻詞組搭配（列出：___、___、___）
- [ ] 無低效流水賬句子

### 準則二：邏輯咬合力

- [ ] 包含清晰的邏輯樞紐詞（列出：___）
- [ ] 連接詞覆蓋至少一類邏輯關係（因果 / 讓步轉折 / 條件假設）
- [ ] 遮住連接詞後邏輯鏈會斷裂（即連接詞是承重結構，非裝飾）
- [ ] 能還原出邏輯骨架（背景 → 轉折 → 推導 → 結論）

### 準則三：場景實用性

- [ ] 與我的高頻輸出場景直接掛鉤（場景：___）
- [ ] 非文學散文 / 生活喜劇台詞等語域錯位素材
- [ ] 背下來後能直接遷移到真實工作 / 考試輸出中

### 準則四：語言純淨度

- [ ] 出自母語者語料（非中式英語、非機器翻譯腔）
- [ ] 來源在推薦清單內（白皮書 / 真實商業函件 / Economist / BBC 官方文字稿）
- [ ] 不在避坑清單內（本土模擬題 / 非母語客戶郵件 / 社交媒體短文）

### 準則五（如為自行蒸餾）

- [ ] 已按「鎖定長篇 → 截取壓縮 → 4 句成型 → 字數校準」流程處理
- [ ] 四句結構完整：背景/問題 → 分析 1 → 分析 2 → 結論/行動倡議
- [ ] 蒸餾後重新通過了準則一至四的檢驗
