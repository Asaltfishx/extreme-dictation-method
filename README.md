# 極限默寫法（暗記暗誦法）學習專案

> 源自日本傳奇英語補教名師 **竹岡廣信** 的方法論，收錄於其被日本考生奉為神級參考書的《Dragon English 基本英文100句》。
> 竹岡廣信是知名日劇及漫畫《龍櫻 / 東大特訓班》中英語教師的原型人物。

本專案系統化整理自 YouTube 影片解析：[與 Gemini 對話 — 影片連結](https://www.youtube.com/watch?v=njhGvYkfPYM)，完整呈現這套「透過殘酷但極高效的訓練，徹底治好學生的『啞巴英語』，讓大腦建立真正的母語者直覺」的方法 [00:15]。

## 核心理念

**沒有痛苦的深度提取，就沒有真正的肌肉記憶。**

這套方法扯下了「快樂學習」的遮羞布，直指語言習得的最核心本質：逼迫大腦在毫無提示的絕境下進行深度的主動提取（Active Recall），用「生長痛」把英文內化為本能。

## 快速開始

1. 先讀 [01-方法背景與原理](docs/01-方法背景與原理.md) 與 [03-核心解法：白紙審判](docs/03-核心解法-白紙審判.md)，理解「為什麼」。
2. 用 [05-素材挑選五大準則](docs/05-素材挑選五大準則.md) 與 [素材挑選檢查表](templates/素材挑選檢查表.md)，準備你的第一批微型短文。
3. 依照 [04-極限默寫四步實操指南](docs/04-極限默寫四步實操指南.md)，今晚就對第一篇短文進行第一次「白紙審判」。
4. 用 [每日默寫記錄表](templates/每日默寫記錄表.md) 與 [滾雪球複習追蹤表](templates/滾雪球複習追蹤表.md) 把過程固定下來，熬過前 10 篇的「絕對黑暗期」。
